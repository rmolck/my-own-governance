# Project

## Purpose

`my-own-governance` is the canonical public baseline for governance across a family of independent personal repositories. It supplies reusable safety, documentation, Git, review, and autonomy contracts without centralizing consumer product specifications or operational state. A Linux systemd runtime is included as a reference implementation, not as a requirement of the governance protocol.

## Outcomes

- A consumer can resume safely from versioned repository state without relying on remembered conversation.
- Human material authority remains explicit while reversible local execution does not require unnecessary intervention.
- CODEX WORKER and AI SUPERVISOR responsibilities remain separate and reviewable.
- Consumers can adopt a known governance revision without losing their local instructions.

## Boundaries

This repository contains generic public governance and templates. It does not contain consumer secrets, private facts, product specifications, credentials, production controls, or automation credentials. It provides reference adapter and scheduler code, but installs no running worker, supervisor, scheduler, GitHub Action, auto-merge, or external infrastructure.

## Success criteria

The baseline is coherent, self-contained when projected into a consumer, revision-pinnable, and explicit about authority. Adoption must preserve existing work and keep consumer-specific truth in consumer documents.
