# Project

## Purpose

`my-own-governance` is the canonical public baseline for governance across a family of independent personal repositories. It supplies reusable safety, documentation, Git, review, and autonomy contracts without centralizing consumer product specifications or operational state.

## Outcomes

- A consumer can resume safely from versioned repository state without relying on remembered conversation.
- Human material authority remains explicit while reversible local execution does not require unnecessary intervention.
- CODEX WORKER and AI SUPERVISOR responsibilities remain separate and reviewable.
- Consumers can adopt a known governance revision without losing their local instructions.

## Boundaries

This repository contains generic public governance and templates. It does not contain consumer secrets, private facts, product specifications, credentials, production controls, or automation credentials. It currently provides no running worker, supervisor, scheduler, GitHub Action, auto-merge, or external infrastructure.

## Success criteria

The baseline is coherent, self-contained when projected into a consumer, revision-pinnable, and explicit about authority. Adoption must preserve existing work and keep consumer-specific truth in consumer documents.
